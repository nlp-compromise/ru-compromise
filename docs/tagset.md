# Набор тегов

Теги ru-compromise. Каждый тег можно использовать в шаблонах под английским названием или под русским псевдонимом:

```js
const doc = nlp('Я читаю')
doc.match('#Местоимение #НастоящееВремя')
doc.match('#Pronoun #PresentTense') // то же самое
```

`—` означает, что отдельного псевдонима нет: у тега нет хорошего перевода. Английское название всё равно работает.

`*` означает, что теггер пока не присваивает этот тег данному примеру автоматически. Его можно присвоить с помощью `.tag()`.
