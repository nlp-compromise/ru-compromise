# API

`ru-compromise` построен на английской библиотеке [compromise](https://github.com/spencermountain/compromise/) и использует её основные методы. Они работают одинаково во всех языках.

Большинство методов возвращают новое **представление** (выборку из документа), поэтому их можно вызывать по цепочке:

```js
nlp(text).match('#Существительное').first().text()
```

Методы, которые принимают `match`, используют [синтаксис шаблонов](./match.md).

## Основные методы

_(доступны в любом представлении)_

### Утилиты

- **`.found`** _[getter]_ — есть ли что-нибудь в этом представлении?
- **`.docs`** _[getter]_ — список объектов-термов этого представления
- **`.document`** _[getter]_ — весь разобранный текст
- **`.pointer`** _[getter]_ — индексы текущего представления
- **`.fullPointer`** _[getter]_ — полные индексы текущего представления
- **`.methods`** _[getter]_ — доступ к внутренним методам библиотеки
- **`.model`** _[getter]_ — доступ к внутренним данным библиотеки
- **`.hooks`** _[getter]_ — какие compute-методы запускаются по умолчанию
- **`.isView`** _[getter]_ — позволяет распознать объект compromise
- **`.length`** _[getter]_ — число совпадений в представлении
- **`.update(pointer)`** — создаёт новое представление из этого документа
- **`.toView(pointer)`** — превращает представление Verb или Noun в обычное
- **`.fromText(text)`** — создаёт новый документ
- **`.termList()`** — псевдоним для .docs
- **`.compute(method)`** — выполняет над документом именованную операцию
- **`.clone(shallow?)`** — полностью копирует документ, не оставляя ссылок

### Циклы

- **`.forEach(fn)`** — вызывает функцию для каждого совпадения как для отдельного документа
- **`.map(fn, emptyResult?)`** — пропускает каждое совпадение через функцию и создаёт новый документ
- **`.filter(fn)`** — оставляет только совпадения, для которых функция вернула true
- **`.find(fn)`** — возвращает документ только с первым подходящим совпадением
- **`.some(fn)`** — возвращает true, если подходит хотя бы одно совпадение
- **`.random(n?)`** — случайно выбирает часть совпадений

### Доступ

- **`.terms(n?)`** — разбивает совпадения на отдельные термы
- **`.groups(name?)`** — возвращает именованную группу захвата
- **`.eq(n)`** — оставляет только n-е совпадение
- **`.first(n?)`** — оставляет только первое совпадение (или первые)
- **`.last(n?)`** — оставляет только последнее совпадение (или последние)
- **`.firstTerms()`** — первое слово каждого совпадения
- **`.lastTerms()`** — последнее слово каждого совпадения
- **`.slice(start, end?)`** — берёт часть совпадений
- **`.all()`** — возвращает весь исходный документ («отдалить»)
- **`.fullSentences()`** — возвращает полное исходное предложение для каждого совпадения
- **`.none()`** — возвращает пустое представление
- **`.isDoc(view?)`** — относятся ли эти два представления к одному документу?
- **`.wordCount()`** — считает число термов

### Поиск

- **`.match(match, group?, options?)`** — возвращает части документа, подходящие под шаблон
- **`.matchOne(match, group?, options?)`** — возвращает только первое совпадение
- **`.has(match, group?, options?)`** — возвращает true или false: есть ли такое совпадение?
- **`.if(match, group?, options?)`** — оставляет только те совпадения, в которых есть этот шаблон
- **`.ifNo(match, group?, options?)`** — убирает совпадения, в которых есть этот шаблон
- **`.before(match, group?, options?)`** — возвращает термы перед каждым совпадением
- **`.after(match, group?, options?)`** — возвращает термы после каждого совпадения
- **`.lookBehind(match, group?, options?)`** — псевдоним для .before()
- **`.lookBefore(match, group?, options?)`** — псевдоним для .before()
- **`.lookAhead(match, group?, options?)`** — псевдоним для .after()
- **`.lookAfter(match, group?, options?)`** — псевдоним для .after()
- **`.growLeft(match, group?, options?)`** — добавляет в представление подходящие термы непосредственно перед ним
- **`.growRight(match, group?, options?)`** — добавляет в представление подходящие термы непосредственно после него
- **`.grow(match, group?, options?)`** — расширяет представление подходящими термами слева или справа
- **`.sweep(match, opts?)`** — применяет к документу набор подготовленных шаблонов
- **`.splitOn(match?, group?)`** — делит совпадение на три части: до шаблона, сам шаблон и после
- **`.splitBefore(match?, group?)`** — разрезает прямо перед каждым найденным шаблоном
- **`.splitAfter(match?, group?)`** — разрезает сразу после каждого найденного шаблона
- **`.split(match?, group?)`** — псевдоним для .splitAfter()

### Регистр

- **`.toLowerCase()`** — переводит все буквы в нижний регистр
- **`.toUpperCase()`** — переводит все буквы в верхний регистр
- **`.toTitleCase()`** — делает заглавной первую букву каждого терма
- **`.toCamelCase()`** — убирает пробелы и пишет каждый терм с заглавной буквы

### Вставка

- **`.concat(input)`** — добавляет это в конец
- **`.insertBefore(input)`** — добавляет эти слова перед каждым совпадением
- **`.prepend(input)`** — псевдоним для .insertBefore()
- **`.insertAfter(text)`** — добавляет эти слова после каждого совпадения
- **`.append(text)`** — псевдоним для .insertAfter()
- **`.insert(text)`** — псевдоним для .insertAfter()
- **`.remove(match)`** — полностью удаляет эти термы из документа
- **`.delete(match)`** — псевдоним для .remove()
- **`.replace(from, to?, keep?)`** — ищет шаблон и заменяет его новым содержимым
- **`.replaceWith(to, keep?)`** — заменяет выборку новым содержимым
- **`.unique()`** — убирает повторяющиеся совпадения
- **`.reverse()`** — меняет порядок совпадений на обратный, но не порядок слов
- **`.sort(method?)`** — переупорядочивает совпадения (на месте)
<!-- - **`.normalize(options?)`** — приводит в порядок разные свойства слов -->

### Пробелы и пунктуация

- **`.pre(str?, concat?)`** — добавляет этот знак или пробел перед каждым совпадением
- **`.post(str?, concat?)`** — добавляет этот знак или пробел после каждого совпадения
- **`.trim()`** — убирает пробелы в начале и в конце
- **`.hyphenate()`** — соединяет слова дефисом и убирает пробелы
- **`.dehyphenate()`** — убирает дефисы между словами и ставит пробелы
- **`.deHyphenate()`** — псевдоним для .dehyphenate()
- **`.toQuotations(start?, end?)`** — заключает выборку в кавычки
- **`.toQuotation(start?, end?)`** — псевдоним для .toQuotations()
- **`.toParentheses(start?, end?)`** — заключает выборку в скобки

### Вывод

- **`.text(options?)`** — возвращает документ в виде текста
- **`.json(options?)`** — возвращает нужные метаданные документа
- **`.debug()`** — наглядно печатает текущий документ и его теги
- **`.out(format?)`** — несколько именованных форматов вывода
- **`.html(toHighlight)`** — создаёт html-строку с тегами вокруг найденных шаблонов
- **`.wrap(matches)`** — создаёт собственный вывод вокруг найденных шаблонов

### Указатели

- **`.union(match)`** — возвращает все совпадения без повторов
- **`.and(match)`** — псевдоним для .union()
- **`.intersection(match)`** — возвращает только общие совпадения
- **`.not(match, options?)`** — возвращает все совпадения, кроме этого
- **`.difference(match, options?)`** — псевдоним для .not()
- **`.complement(match)`** — возвращает всё, что не является совпадением
- **`.settle(match)`** — убирает пересечения между совпадениями

### Теги

- **`.tag(tag, reason?)`** — присваивает этот тег всем термам
- **`.tagSafe(tag, reason?)`** — присваивает тег, только если он совместим с текущими тегами
- **`.unTag(tag, reason?)`** — снимает этот тег с термов
- **`.canBe(tag)`** — возвращает только те термы, которые могут иметь этот тег

### Кэш

- **`.cache(options?)`** — замораживает текущее состояние документа ради скорости
- **`.uncache(options?)`** — размораживает состояние документа, чтобы его можно было преобразовывать
- **`.freeze()`** — запрещает снимать текущие теги
- **`.unfreeze()`** — разрешает менять текущие теги [по умолчанию]

### Поиск по списку

- **`.lookup(trie, opts?)`** — быстрый поиск по списку слов
- **`.autoFill()`** — дополняет начала слов по словарю автодополнения

## Выборки

Выборки — это готовые поиски, такие как `.verbs()` или `.nouns()`, которые возвращают представление с дополнительными собственными методами.
Они пишутся отдельно для каждого языка, поэтому доступные здесь выборки отличаются от английских.

### `.nouns()`

- **`.nouns()`** — возвращает существительные документа
- **`.nouns().decline()`** — даёт все падежные формы каждого существительного, в единственном и множественном числе
- **`.nouns().gender()`** — возвращает род каждого существительного
- **`.nouns().isFeminine()`** — возвращает только существительные женского рода
- **`.nouns().isMasculine()`** — возвращает только существительные мужского рода
- **`.nouns().isNeuter()`** — возвращает только существительные среднего рода
- **`.nouns().isAnimate()`** — возвращает только одушевлённые существительные
- **`.nouns().toPlural()`** — ставит существительные во множественное число и согласует с ними слова вокруг
- **`.nouns().toSingular()`** — ставит существительные в единственное число и согласует с ними слова вокруг

### `.verbs()`

- **`.verbs()`** — возвращает глаголы документа
- **`.verbs().conjugate()`** — даёт все формы спряжения каждого глагола
- **`.verbs().toPresentTense()`** — ставит глаголы в настоящее время
- **`.verbs().toPastTense()`** — ставит глаголы в прошедшее время
- **`.verbs().toFutureTense()`** — ставит глаголы в будущее время
- **`.verbs().toInfinitive()`** — ставит глаголы в инфинитив

### `.adjectives()`

- **`.adjectives()`** — возвращает прилагательные документа
- **`.adjectives().toMasculine()`** — ставит прилагательные в мужской род
- **`.adjectives().toFeminine()`** — ставит прилагательные в женский род
- **`.adjectives().toNeuter()`** — ставит прилагательные в средний род
- **`.adjectives().toPlural()`** — ставит прилагательные во множественное число
- **`.adjectives().toComparative()`** — ставит прилагательные в сравнительную степень
- **`.adjectives().toSuperlative()`** — ставит прилагательные в превосходную степень

## Методы конструктора

_(вызываются у импортированного объекта `nlp`, а не у представления)_

- **`nlp.tokenize(text, lexicon?)`** — разбирает текст, не запуская теггер
- **`nlp.plugin(plugin)`** — подключает плагин compromise
- **`nlp.extend(plugin)`** — псевдоним для nlp.plugin()
- **`nlp.addWords(words, isFrozen?)`** — добавляет новые слова во внутренний словарь
- **`nlp.addTags(tags)`** — добавляет новые теги в набор тегов
- **`nlp.parseMatch(match, opts?)`** — превращает шаблон в json
- **`nlp.buildNet(matches)`** — собирает набор шаблонов в более быструю форму, для .sweep()
- **`nlp.buildTrie(words)`** — собирает список слов в более быструю форму, для .lookup()
- **`nlp.typeahead(words)`** — добавляет слова в словарь автодополнения
- **`nlp.world()`** — доступ к внутренним данным библиотеки
- **`nlp.model()`** — доступ к языковым данным библиотеки
- **`nlp.methods()`** — доступ к внутренним методам библиотеки
- **`nlp.hooks()`** — какие compute-функции запускаются автоматически
- **`nlp.verbose(toLog?)`** — печатает решения теггера, для отладки
- **`nlp.version`** — текущая semver-версия библиотеки
