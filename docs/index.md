# ru-compromise

`ru-compromise` — это JavaScript-библиотека для разбора русского текста.

Она делит русский текст на предложения и слова и присваивает каждому слову тег его части речи.
После этого части документа можно находить по шаблону, похожему на регулярное выражение, или преобразовывать.

Библиотека достаточно мала, чтобы работать в браузере, работает без сети и не имеет зависимостей.
Она основана на правилах и настраивается. Она принимает быстрые и «достаточно хорошие» решения и не использует нейронную модель.

Это русская версия исходной [английской библиотеки](https://github.com/spencermountain/compromise/).

```bash
npm install ru-compromise
```

```js
import nlp from 'ru-compromise'

const doc = nlp('Она читает книгу в саду.')
doc.match('#Глагол').text() // 'читает'
```

или в браузере:

```html
<script src="https://unpkg.com/ru-compromise"></script>
```

### Как это работает

Текст разбирается в список предложений, а каждое предложение — в список термов:

```
Sentence [
  Term { text: 'Она', pre: '', post: ' ', normal: 'она', tags: ['Noun', 'Pronoun'] },
  Term { text: 'читает', pre: '', post: ' ', normal: 'читает', tags: ['Verb', 'PresentTense', 'ThirdPerson'] },
  ...
]
```

- `text` — слово в том виде, в каком оно написано
- `pre` и `post` — пробелы и знаки препинания вокруг него
- `normal` — очищенная форма, которая используется при поиске
- `tags` — его [теги частей речи](./tagset.md)

Эти данные можно получить с помощью `.json()`:

```js
const doc = nlp('Она читает книгу в саду.')
doc.json()
// [{ terms: [{ text: 'Она', tags: ['Noun', 'Pronoun'], ... }, ...] }]
```

### Поиск

Чтобы выбрать части документа, используйте `.match()`:

```js
const doc = nlp('Она читает книгу в саду.')
const m = doc.match('#Местоимение читает .')
m.text() // 'Она читает книгу'
m.json() // [{ text: 'Она читает книгу', terms: [...] }]

doc.has('#Глагол #Существительное') // true
doc.match('#Существительное').out('array') // ['Она', 'книгу', 'саду.']
```

В разделе [Синтаксис шаблонов](./match.md) описано всё, что умеет шаблон, а в [наборе тегов](./tagset.md) перечислены поддерживаемые теги.

### Преобразование

Части документа можно преобразовывать, и изменение применяется к исходному документу:

```js
const doc = nlp('Она читает книгу в саду.')
doc.match('книгу').replaceWith('старую газету')
doc.text() // 'Она читает старую газету в саду.'
```

Есть и готовые выборки, такие как `.verbs()`, `.nouns()` и `.adjectives()`<!--, `.numbers()` -->, у которых есть собственные методы, например `.conjugate()` или `.toPlural()`:

```js
const doc = nlp('новая книга лежала на столе')
doc.nouns().length // 2 ('книга', 'столе')

doc.nouns().toPlural()
doc.text() // 'новые книги лежали на столе'

doc.nouns().toSingular()
doc.text() // 'новая книга лежала на столе'
```

Эти выборки в разных языках разные. Те, что есть в этой библиотеке, перечислены в [API](./api.md).

### Что нужно знать

**Каждый метод возвращает представление.** Представление — это выборка термов документа. `nlp(text)` — это представление всего документа, а `.match()` возвращает меньшее. Большинство методов возвращают представление, поэтому их можно вызывать по цепочке. Чтобы вернуться ко всему документу, используйте `.all()`.

**Преобразования меняют сам документ.** Представление, которое возвращает преобразование, содержит только выборку, поэтому результат нужно читать из исходного документа:

```js
const doc = nlp('Она читает книгу в саду.')
doc.match('книгу').replaceWith('газету').text() // 'газету' (только выборка)
doc.text() // 'Она читает газету в саду.'
```

Чтобы не трогать оригинал, работайте с копией, созданной через `.clone()`:

```js
const doc = nlp('Она читает книгу в саду.')
const copy = doc.clone()
copy.match('в саду').remove()
copy.text() // 'Она читает книгу.'
doc.text() // 'Она читает книгу в саду.'
```

**Шаблон не выходит за пределы предложения.**

```js
nlp('Вот и всё. Назад в Виннипег!').has('всё назад') // false
```

**Неизвестный тег ничего не находит и не вызывает ошибки.** Если поиск ничего не вернул, сверьте тег с [набором тегов](./tagset.md) и вызовите `doc.debug()`, чтобы увидеть, какие теги получило каждое слово.

### Настройка

Если слово размечено неверно или его нет в словаре, его можно задать самостоятельно:

```js
// для одного документа
nlp('кермит помахал', { кермит: 'Имя' }).match('#Имя').text() // 'кермит'

// для всех документов
nlp.addWords({ кермит: 'Имя' })
```

Теги должны быть из [набора тегов](./tagset.md) или добавлены через `nlp.addTags()`.

Плагин может добавить сразу слова, теги и новые методы:

```js
nlp.plugin({
  words: { кермит: 'Имя' },
  tags: { Muppet: { isA: 'Персона' } },
  api: (View) => {
    View.prototype.exclaim = function () {
      return this.post('!')
    }
  }
})

const doc = nlp('привет всем')
doc.match('всем').exclaim()
doc.text() // 'привет всем!'
```
