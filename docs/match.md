# Синтаксис шаблонов

Это язык шаблонов, с помощью которого compromise выбирает части документа.
Он похож на регулярное выражение, но работает с целыми словами (термами), а не с символами.
Его используют `.match()`, `.has()`, `.if()`, `.not()`, `.before()`, `.replace()` и похожие методы.

```js
nlp('эта кошка спит').match('#Определитель #Существительное').text()
// 'эта кошка'
```

## Краткая справка

| Шаблон          | Значение                                     | Пример                            | Находит                                  |
| --------------- | -------------------------------------------- | --------------------------------- | ---------------------------------------- |
| `слово`         | именно это слово (без учёта регистра)        | `спит`                            | «спит»                                   |
| `#Тег`          | любой терм с этим [тегом](./tagset.md)       | `#Существительное`                | «кошка»                                  |
| `.`             | один любой терм                              | `эта . спит`                      | «эта кошка спит»                         |
| `*`             | ноль или больше любых термов                 | `эта * спит`                      | «эта чёрная кошка спит»                  |
| `(a\|b)`        | одно из двух                                 | `(красный\|синий)`                | «красный» или «синий»                    |
| `(a && b)`      | терм, который является и тем и другим        | `(красная && #Прилагательное)`    | «красная», только как прилагательное     |
| `слово?`        | необязательный терм                          | `эта маленькая? машина`           | «эта машина» и «эта маленькая машина»    |
| `слово+`        | один или больше                              | `#Прилагательное+`                | «маленькая красная»                      |
| `слово{m,n}`    | от m до n                                    | `.{2,3}`                          | два или три терма                        |
| `!слово`        | что угодно, кроме этого                      | `эта !#Глагол`                    | «эта кошка»                              |
| `^`             | начало предложения                           | `^эта`                            | «эта» в начале предложения               |
| `$`             | конец предложения                            | `спит$`                           | «спит» в конце предложения               |
| `[слово]`       | группа захвата                               | `цена на [.]`                     | «молоко»                                 |
| `[<имя>слово]`  | именованная группа захвата                   | `цена на [<товар>.]`              | «молоко», под именем `товар`             |
| `{корень}`      | любая форма этого слова                      | `{читать}`                        | «читать», «читает», «читал»              |
| `~слово~`       | нечёткий поиск, для близких написаний        | `~программа~`                     | «програма»                               |
| `/regex/`       | регулярное выражение, проверяется на одном терме | `/н[оу]ль/`                   | «ноль», «нуль»                           |
| `@метод`        | проверка терма                               | `@isUpperCase`                    | «НАТО»                                   |

Их можно сочетать: `#Существительное+?` — это необязательная цепочка существительных, а `^[<первое>.]` захватывает первый терм.

## Слова

Обычное слово находит только само это слово, без учёта регистра. Другие формы слова оно не находит:

```js
nlp('мы шли на работу').has('шли') // true
nlp('мы шли на работу').has('идти') // false
```

Чтобы найти все формы, используйте `{идти}`. См. раздел [Начальные формы](#начальные-формы) ниже.

## Теги

`#Тег` находит любой терм с этим тегом. Допустимые теги перечислены в [наборе тегов](./tagset.md).

Теги образуют иерархию: `#Имя` — это также `#Персона` и `#Существительное`.

```js
nlp('эта кошка спит').match('#Существительное').text() // 'кошка'
```

Неизвестный тег ничего не находит и не вызывает ошибки:

```js
nlp('эта кошка спит').match('#Существительные').found // false
```

Русские и английские названия тегов взаимозаменяемы. Можно использовать и формы в стиле Penn, например `#RB`.

```js
nlp('эта кошка спит').match('#Определитель #Существительное').text() // 'эта кошка'
nlp('эта кошка спит').match('#Determiner #Noun').text() // 'эта кошка'
```

## Подстановочные знаки

`.` — это ровно один терм. `*` — это любое число термов, в том числе ни одного, и он захватывает как можно больше.

```js
nlp('эта кошка спит').match('эта . спит').text() // 'эта кошка спит'
nlp('эта чёрная кошка спит').match('эта * спит').text() // 'эта чёрная кошка спит'
```

## Варианты

`(a|b)` находит любой из вариантов. `(a && b)` требует, чтобы терм подходил под все условия сразу. Это полезно для слова, которое может быть двумя частями речи.

```js
nlp('я люблю красный и синий').match('(красный|синий)').out('array') // ['красный', 'синий']
nlp('эта красная машина').match('(красная && #Прилагательное)').text() // 'красная'
```

Группы нельзя вкладывать друг в друга. `(большая (красная|синяя))` не поддерживается, вместо этого используйте два вызова `.match()`.

## Необязательные и повторяющиеся термы

```js
nlp('эта машина').match('эта маленькая? машина').text() // 'эта машина'
nlp('эта маленькая машина').match('эта маленькая? машина').text() // 'эта маленькая машина'

nlp('эта маленькая красная машина').match('#Прилагательное+').text() // 'маленькая красная'
nlp('а б в г').match('.{2,3}').text() // 'а б в'
```

`{n}` означает ровно n, `{m,n}` — от m до n, `{m,}` — m или больше, а `{,n}` — до n.

## Отрицание

```js
nlp('эта кошка спит').match('эта !#Глагол').text() // 'эта кошка'
```

## Начало и конец

`^` и `$` — это начало и конец предложения, а не документа.

```js
nlp('эта кошка спит').match('^эта').text() // 'эта'
nlp('эта кошка спит').match('спит$').text() // 'спит'
```

## Группы захвата

Квадратные скобки отмечают ту часть совпадения, которую нужно сохранить. Получить её можно через `.groups()` или передав группу вторым аргументом:

```js
const doc = nlp('цена на молоко высокая')
doc.match('цена на [<товар>.]').groups('товар').text() // 'молоко'
doc.match('цена на [.]', 0).text() // 'молоко'
```

Группы без имени нумеруются с 0. В группе может быть несколько термов.

## Начальные формы

`{корень}` находит любую форму слова по его словарной форме:

```js
nlp('мы шли на работу').match('{идти}').text() // 'шли'
nlp('он читал газету').match('{читать}').text() // 'читал'
```

<!-- Начальные формы не вычисляются по умолчанию. Если поиск ничего не находит, сначала вызовите `doc.compute('root')`. -->

## Нечёткий поиск

`~слово~` находит близкие написания по расстоянию между строками. Порог по умолчанию равен 0,85, и его можно изменить в [параметрах](#параметры-поиска).

```js
nlp('это програма').match('~программа~').text() // 'програма'
```

## Регулярные выражения

`/regex/` проверяется на одном терме за раз, поэтому не может охватывать два слова.

```js
nlp('ноль нуль').match('/н[оу]ль/').out('array') // ['ноль', 'нуль']
```

## Проверки термов

`@метод` применяет к каждому терму встроенную проверку. Самые частые — `@isTitleCase`, `@isUpperCase`, `@hasComma`, `@hasHyphen`, `@hasContraction` и `@hasQuote`.

```js
nlp('НАТО и кошка').match('@isUpperCase').out('array') // ['НАТО']
```

## Параметры поиска

`.match()`, `.matchOne()`, `.has()`, `.if()`, `.ifNo()`, `.before()` и `.after()` принимают третьим аргументом, после группы захвата, объект с параметрами.

| Параметр        | По умолчанию | Действие                                                              |
| --------------- | ------------ | --------------------------------------------------------------------- |
| `fuzzy`         | `0.85`       | сходство, нужное для совпадения `~слово~`, от 0 до 1                  |
| `caseSensitive` | `false`      | сравнивает с исходным текстом, а не с нормализованной формой          |
| `noRegex`       | `false`      | считает `/regex/` обычным словом, так что оно никогда не выполняется  |

```js
nlp('Привет привет').match('Привет', null, { caseSensitive: true }).out('array') // ['Привет']
```

Используйте `{ noRegex: true }`, когда шаблон написан пользователем, чтобы медленное или неверное регулярное выражение не могло выполниться.

## Поиск по списку слов

Для длинного списка обычных слов `.lookup()` намного быстрее, чем много вызовов `.match()`. Этот метод не использует синтаксис шаблонов, поэтому он безопасен и для слов, введённых пользователем.

```js
nlp('я видел марию и ивана').lookup(['марию', 'ивана']).out('array') // ['марию', 'ивана']
```

## Повторное использование шаблона

`nlp.parseMatch(str)` разбирает шаблон один раз, чтобы его можно было использовать многократно. `nlp.buildNet([...])` собирает много шаблонов в один, который запускается через `.sweep()`. Это полезно, когда одни и те же шаблоны применяются к большому объёму текста.

## Что не поддерживается

- **Вложенные группы.** Используйте несколько вызовов `.match()`.
- **Шаблоны через границу предложения.** Каждое совпадение остаётся внутри одного предложения.
- **Регулярное выражение на несколько слов.** `/regex/` проверяется на одном терме за раз.

## Если поиск ничего не находит

1. Проверьте, что тег есть в [наборе тегов](./tagset.md).
2. Вызовите `doc.debug()`, чтобы увидеть, какие теги получило каждое слово.
3. Помните, что обычное слово ищется точно. Для всех его форм используйте `{корень}`.
4. Помните, что шаблон не выходит за пределы предложения.
