# Участие в разработке

Эта библиотека ещё в разработке и зависит от помощи как разработчиков, так и носителей русского языка.

Чтобы помочь, не обязательно быть программистом. Сообщение о неверно размеченном слове, оставленное в [issue](https://github.com/nlp-compromise/ru-compromise/issues), — уже полезный вклад. Писать можно по-русски или по-английски.

Мы рады всем pull-request'ам и рассматриваем их в разумные сроки. Это библиотека с открытым исходным кодом под лицензией MIT.

### Установка

Создайте на GitHub собственный форк репозитория, затем:

```bash
git clone git@github.com:{ВАШЕ_ИМЯ}/ru-compromise.git
cd ru-compromise
pnpm install
pnpm test
```

В этом проекте используется [pnpm](https://pnpm.io/). `npm install` и `npm test` тоже работают.

### Как внести изменение

- В `./src` лежит код. Он разделён на `01-one` (разбиение на слова), `02-two` (разметка тегами) и `03-three` (выборки вроде `.verbs()`).
- В `./data` лежат списки слов и модели. Они сжаты, поэтому после изменений запустите `pnpm run pack`, чтобы увидеть результат.
- В `./tests` лежат тесты. Пожалуйста, добавьте тест для своего изменения.
- `./scratch.js` — это файл для экспериментов. `pnpm run watch` перезапускает его при каждом сохранении.

Чтобы увидеть, как было размечено предложение, используйте `.debug()`:

```js
nlp('Она читает книгу в саду.').debug()
```

### Отправка pull-request'а

Пожалуйста, работайте от ветки `dev` и отправляйте pull-request в неё.

Если изменение большое, сначала создайте issue, чтобы мы могли его обсудить.
